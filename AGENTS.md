# my-agents-rules

Общие правила для агентов (Claude Code, Codex) во всех проектах пользователя и скрипты,
которые доставляют их в каждую среду. Этот файл — для агента, который работает с самим
репозиторием. Правила для всех агентов — в `rules/`, описание для людей — в `README.md`.

## Правила репозитория

- **Репозиторий публичный: всё, что сюда попадает, видят все и навсегда.** Удалить
  pull request нельзя, только закрыть; коммиты удалённой ветки остаются доступны, у других
  остаются их клоны и форки. Здесь — только общие правила, которые подходят любому проекту.
  - **Нельзя:** устройство инфраструктуры пользователя; имена и адреса серверов, доменов,
    клиентов, проектов и приватных репозиториев; стек, сервисы и инструменты пользователя;
    личные данные. Устройства называй по роли («компьютер», «телефон»), не по марке.
  - **Можно:** общие условия работы, которые одобрил пользователь — язык интерфейса,
    работа с телефона и голосом.
  - Это касается не только файлов, но и сообщений коммитов, имён веток и описаний
    pull request.
  - Правилу нужна конкретика — его место в `AGENTS.md` того проекта.
  - **Перед каждым push покажи пользователю в чате, что уходит:** файлы, сообщения
    коммитов, описание pull request. Отправляй только после явного «да». Сомневаешься —
    спроси до коммита. Если сюда всё же попал секрет — удалять бесполезно, его сразу
    заменяют.
- **Изменения — только веткой и pull request.** Ветка `main` защищена (ruleset без
  исключений): прямой push отклоняется у всех, в том числе с компьютера. Вливает пользователь.
- **Коммит — через gitleaks** (`hooks/pre-commit`). В новом клоне без общего хука:
  `git config core.hooksPath hooks`.
- Язык — русский: правила, документация, комментарии и коммиты. Сообщение коммита
  заканчивается строкой `Co-Authored-By`.
- Правки в `rules/` действуют: в облачной сессии — с нового контейнера; на компьютере — после
  `git pull` пользователем; в воркспейсах — после того, как их обновит инфраструктура.
  Агент сам `git pull` на компьютере не делает.
- Скрипты — POSIX `sh`, без зависимостей кроме `git`, `curl`, `python3`. `cloud/install.sh`
  не должен падать: сбой setup script не даёт начать облачную сессию.

## Структура

```
rules/base.md       общие принципы — везде
rules/cloud.md      добавка для облачной сессии
bin/agent-env.sh    где запущен агент (хук SessionStart Claude Code)
hooks/pre-commit    gitleaks — общий хук для всех репозиториев
cloud/install.sh    установка в облачной сессии (из setup script окружения)
```

Добавки для других сред (например, для воркспейса) живут в репозитории, который эту среду
создаёт, и подключаются вместе с `rules/base.md`.
