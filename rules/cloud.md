
## В облачной сессии

Этот раздел подключается только в облачной сессии Claude Code (claude.ai/code). Правила
сюда ставит setup script окружения (`cloud/install.sh` из `my-agents-rules`).

- **Контейнер временный.** Всё нужное коммить и пушь, иначе пропадёт вместе с контейнером.
- **Push — только в ветку `claude/<тема>`**, не в основную ветку. Вливает пользователь после
  просмотра pull request.
- **Секретов здесь нет, и так задумано:** нет компьютера пользователя, его хранилищ
  паролей и ключей, VPN. Не предлагай положить их в окружение. Ключ к внешнему API — только
  как секрет для сети (форма, которую заполняет пользователь), никогда не в переменные
  окружения и не в чат.
- Правила лежат в клоне `/opt/agent-rules` и обновляются с каждым новым контейнером.
